# Deploy — Cloudflare Workers

```text
your-domain.com/*
  createDunetaWorker (worker.ts)
    /api/*  → Hono (`duneta/routes` + `duneta/http`, middleware: `duneta/middleware/http`)
    static  → ASSETS (auto — app/build/client)
    /*      → React Router SSR (`routes/web.ts`, middleware: `duneta/middleware/page`)
```

## Commands

```bash
pnpm dev      # local :8787 (HMR)
pnpm build    # sync + build app/
pnpm deploy   # build + wrangler deploy
```

## Production checklist

- [ ] **`config/server.ts`** — `process.env.*` refs for auth/csrf (không literal secrets)
- [ ] **Hyperdrive** — required when `database.enabled` ([supported DBs](https://developers.cloudflare.com/hyperdrive/reference/supported-databases-and-features/)); one wrangler binding per `connections.*.hyperdrive`
- [ ] **`wrangler secret put`** — AUTH_SECRET, CSRF_SECRET (DB credentials live on the Hyperdrive config, not Worker secrets)
- [ ] **`secrets.required`** trong `wrangler.jsonc`
- [ ] **CI build sạch** — không `.env` / secret env vars lúc `pnpm build`
- [ ] **Optional** — Redis HTTP URL trong `cache` config (distributed cache + rate limit)
- [ ] **Logging** — JSON stdout (`logging.enabled` in `config/server.ts`)
- [ ] **Auth cookies** — `secure: true` applied automatically when `NODE_ENV=production`

## wrangler configs

| File | Purpose |
|------|---------|
| `wrangler.jsonc` | Dev + Vite build (`main: worker.ts`) |
| `wrangler.production.jsonc.example` | Reference template (Hyperdrive, R2) |
| `app/build/server/wrangler.json` | Generated by `pnpm build` — used by `pnpm deploy` |

Example bindings:

```jsonc
{
  "name": "duneta",
  "main": "worker.ts",
  "compatibility_flags": ["nodejs_compat"],
  "hyperdrive": [
    { "binding": "HYPERDRIVE", "id": "<your-hyperdrive-config-id>" }
    // second DB:
    // { "binding": "HYPERDRIVE_ANALYTICS", "id": "<second-id>" }
  ]
}
```

Matching `config/server.ts`:

```ts
import { defineConnections, defineServerConfig, postgres } from 'duneta/config/server';

export default defineServerConfig({
  database: {
    enabled: true,
    default: 'primary',
    connections: defineConnections({
      primary: postgres('HYPERDRIVE'),
      // analytics: postgres('HYPERDRIVE_ANALYTICS'),
    }),
  },
});
```

Local: `localConnectionString` trên Hyperdrive binding trong `wrangler.jsonc`.  
Pool: `maxUses: 1`, dispose sau mỗi request.

Static assets (`app/build/client`) được gắn tự động trong `app/build/server/wrangler.json` khi `pnpm build` — không khai báo trong `wrangler.production.jsonc.example`.

## Config

Secrets: `wrangler secret put` → runtime `process.env` → `config/server.ts`. DB URL: Hyperdrive binding only. Web: `config/client.ts` only.

## Observability

Workers have **no persistent filesystem**. Logs go to stdout → Wrangler tail / Dashboard / Logpush.

Request logs (when `logging.enabled`):

```json
{"level":"info","msg":"request","ts":"...","requestId":"...","method":"GET","path":"/api/health","status":200,"durationMs":12}
```
