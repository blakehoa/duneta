# Deploy — Cloudflare Workers

```text
your-domain.com/*
  createDunetaWorker (worker.ts)
    /api/*  → Hono (`duneta/routes` + `duneta/http`, middleware: `duneta/middleware/http`)
    static  → ASSETS (auto — app/build/client)
    /*      → React Router SSR (`routes/web.ts`, middleware: `duneta/middleware/page`)
```

## Commands

```bash
pnpm dev      # local :8787 (HMR)
pnpm build    # sync + build app/
pnpm deploy   # build + wrangler deploy
```

## Production checklist

- [ ] **`wrangler.production.jsonc`** — real Hyperdrive `id`, `vars.NODE_ENV=production`, `vars.AUTH_BASE_URL`
- [ ] **`wrangler secret put`** — AUTH_SECRET, CSRF_SECRET
- [ ] **Hyperdrive** — required when `database.enabled` ([supported DBs](https://developers.cloudflare.com/hyperdrive/reference/supported-databases-and-features/))
- [ ] **CI build sạch** — không `.env` / secret env vars lúc `pnpm build`
- [ ] **Optional** — Redis HTTP URL trong `cache` config (distributed cache + rate limit)

Production rate limiting requires Redis HTTP or a distributed custom cache. The in-memory
fallback is isolate-local and is intended for development only.

- [ ] **Logging** — JSON stdout (`logging.enabled` in `config/server.ts`)
- [ ] **Auth cookies** — `secure: true` applied automatically when `NODE_ENV=production`

## wrangler configs

| File                             | Purpose                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------- |
| `wrangler.jsonc`                 | Local `duneta dev` (`localConnectionString` OK)                                 |
| `wrangler.production.jsonc`      | `duneta build` / `duneta deploy` (real Hyperdrive id, no localConnectionString) |
| `app/build/server/wrangler.json` | Generated by build — used by `duneta deploy`                                    |

`duneta build`/`deploy` set `NODE_ENV=production` and pick `wrangler.production.jsonc` when that file exists. Deploy fails if the generated config still contains `localConnectionString` or a placeholder Hyperdrive id.

Example production bindings:

```jsonc
{
  "name": "duneta",
  "main": "worker.ts",
  "compatibility_flags": ["nodejs_compat"],
  "vars": {
    "NODE_ENV": "production",
    "AUTH_BASE_URL": "https://your-domain.example",
  },
  "hyperdrive": [
    { "binding": "HYPERDRIVE", "id": "<your-hyperdrive-config-id>" },
  ],
}
```

Matching `config/server.ts`:

```ts
import {
  defineConnections,
  defineServerConfig,
  postgres,
} from 'duneta/config/server';

export default defineServerConfig({
  database: {
    enabled: true,
    default: 'primary',
    connections: defineConnections({
      primary: postgres('HYPERDRIVE'),
    }),
  },
  auth: {
    enabled: true,
    baseUrl: process.env.AUTH_BASE_URL ?? '',
    secret: process.env.AUTH_SECRET ?? '',
  },
});
```

Local: `localConnectionString` trên Hyperdrive binding trong `wrangler.jsonc`.  
Mỗi HTTP request hoặc cron invocation dùng một `pg.Client` riêng. Không cấu hình `pg.Pool`
trong Worker và không gọi `client.end()`; Hyperdrive quản lý connection pool phía database và
Workers tự dọn edge connection khi invocation kết thúc.

Static assets (`app/build/client`) được gắn tự động trong `app/build/server/wrangler.json` khi `pnpm build`.

## Config

Secrets: `wrangler secret put` → runtime `process.env` → `config/server.ts`. DB URL: Hyperdrive binding only. Web: `config/client.ts` only.

## Observability

Workers have **no persistent filesystem**. Logs go to stdout → Wrangler tail / Dashboard / Logpush.

Request logs (when `logging.enabled`):

```json
{
  "level": "info",
  "msg": "request",
  "ts": "...",
  "requestId": "...",
  "method": "GET",
  "path": "/api/health",
  "status": 200,
  "durationMs": 12
}
```
